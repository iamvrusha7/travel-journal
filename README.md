# Travel Journal
## Live Demo

[View the Travel Journal](https://travel-journal-gamma-nine.vercel.app)

A scrapbook-style travel journal built using React and Vite.

## About the Project

This project displays different travel destinations in a creative journal-style layout.

Each destination includes:

- Travel photo
- Country name
- Place name
- Travel dates
- Short description
- Google Maps link

## Destinations

- Mount Fuji, Japan
- Sydney Opera House, Australia
- Geirangerfjord, Norway
